# vLLM for fast generation (5-20x faster than transformers).
# NOTE: TRL 0.17 supports vLLM 0.19.0-0.27.1 only. vLLM 0.28+ breaks the
# GRPO weight-transfer import (NCCLTrainerSendWeightsArgs), so pin the range.
# Install AFTER requirements.txt:
#   pip install -r requirements-vllm.txt
# If pip wants to downgrade your torch (CUDA conflict), or vLLM still
# misbehaves, `pip uninstall -y vllm` - generation then falls back to
# transformers and GRPO falls back to torch rollouts (slower but works).
vllm>=0.19.0,<0.28.0
